# Развёртывание Claude Anonymizer (Python + FastAPI + PostgreSQL)

## Шаг 1. Установите Python зависимости

Откройте терминал (PowerShell или cmd) в папке проекта:

```powershell
cd C:\Users\vlsta\projects\Python_anonimizer_SUPR
pip install -r requirements.txt
```

## Шаг 2. Установите PostgreSQL

Если PostgreSQL ещё не установлен:

1. Скачайте установщик с https://www.enterprisedb.com/download-postgresql-binaries
2. Установите PostgreSQL 15 или 16
3. Во время установки задайте пароль пользователю `postgres` (запишите его)
4. После установки убедитесь, что сервис `postgresql-x64-16` запущен

## Шаг 3. Создайте базу данных

Откройте командную строку от имени администратора или под пользователем postgres:

```powershell
# Войти в psql (по умолчанию пароль, который задали при установке)
psql -U postgres

# Внутри psql создать базу и пользователя:
CREATE USER app_user WITH PASSWORD 'app_password';
CREATE DATABASE claude_anonimizer OWNER app_user ENCODING 'UTF8' TEMPLATE template0;
\q
```

## Шаг 4. Настройте .env

Откройте файл `.env` и укажите реальные значения:

```
CLAUDE_API_KEY=sk-ant-ВАШ_КЛЮЧ_ANTHROPIC
CLAUDE_MODEL=claude-3-haiku-20240307
DATABASE_URL=postgresql://app_user:app_password@localhost:5432/claude_anonimizer
APP_SECRET=любой-секретный-ключ
LOG_LEVEL=INFO
```

## Шаг 5. Примените схему базы данных

```powershell
psql -U app_user -d claude_anonimizer -f init_db.sql
```

## Шаг 6. Запустите сервер

```powershell
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

## Шаг 7. Откройте веб-интерфейс

Перейдите в браузере по адресу:

```
http://localhost:8000/ui
```

В веб-чате укажите `User ID` (например, `1`) и `Session ID` (например, `web_1`), затем пишите сообщения. Персональные данные (имена, телефоны, email, ИНН, компании) будут заменены на псевдонимы с уникальными номерами (`[ИМЯ_1]`, `[TEL_1]`, `[EMAIL_1]` и т.д.) перед отправкой в Claude. В ответе псевдонимы автоматически подставятся обратно на реальные значения из локальной базы PostgreSQL.

## API эндпоинты

| Метод | Путь | Описание |
|-------|------|----------|
| POST | `/chat` | Отправка сообщения в Claude с обезличиванием |
| GET | `/map/{session_id}` | Карта псевдонимов сессии |
| POST | `/clear/{session_id}` | Очистка карты сессии |
| GET | `/ui` | Веб-чат |

Пример запроса к `/chat`:

```json
POST http://localhost:8000/chat
Headers:
  X-User-ID: 1
  X-Session-ID: chat_123
  Content-Type: application/json

Body:
{
  "messages": [{"role": "user", "content": "Здравствуйте, меня зовут Иван Иванов, мой телефон +7 999 123 45 67, email ivan@company.ru"}],
  "session_id": "chat_123",
  "user_id": 1
}
```

## Проверка работы

1. Напишите в чате сообщение с персональными данными.
2. Откройте `http://localhost:8000/map/chat_123` — увидите соответствие псевдонимов и оригиналов.
3. В ответе Claude реальные данные будут восстановлены.
